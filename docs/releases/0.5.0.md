# VT7Pty 0.5.0

VT7Pty 0.5.0 is the first baseline release of the WinPTY-derived, user-mode
console backend for x64 Windows 7 SP1 and later. It establishes the maintained
native build, diagnostic, test, and manual release foundation for future
application-fidelity work and eventual VT7 integration.

This release modernizes the inherited native implementation and build to
Visual Studio 2022, MSBuild, and C++20. It removes the Unix adapter, obsolete
toolchains and packaging, and XP/Vista compatibility paths. The DLL, agent,
headers, 19 exported C functions, diagnostics, and client-agent handshake now
carry VT7Pty identity. The public C API is version 1.0; the internal
client-agent protocol is version 1.

The release set contains separate runtime, development, symbols, and
self-contained Windows 7 test ZIPs, plus a release-set manifest and SHA-256
checksum file. The runtime uses a statically linked MSVC runtime. Each archive
contains its own manifest and attribution. Run the same test ZIP on the
non-ESU, ESU, and PowerShell 2.0 Windows 7 acceptance machines when qualifying
the exact release build.

The 0.5.x line is pre-stable. VT7Pty 0.5.0 does not provide WinPTY ABI
compatibility, a ConPTY API or driver replacement, or VT7 integration. The
current application tests cover local Command Prompt and Windows PowerShell,
input and Unicode output, resize, lifecycle, diagnostics, fault detection, and
a 120-minute idle/active soak. SSH and full-screen application fidelity remain
Milestone 1 work. Windows XP, Vista, and x86 are outside the maintained target.

See [the changelog](../../CHANGELOG.md) for the complete change list,
[compatibility](../COMPATIBILITY.md) for the tested platform contract,
[Windows 7 acceptance](../WINDOWS7_ACCEPTANCE.md) for target procedures, and
[credits](../../CREDITS.md) for upstream attribution. VT7Pty is an independent
project built on WinPTY by Ryan Prichard and its contributors; Microsoft's
Console, ConPTY, and Windows Terminal work informs its direction.
