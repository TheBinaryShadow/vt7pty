## What I verified

- **Cursor restoration.** I checked the VT stream against the native
  cursor snapshots. The fixed runtime hid the cursor at (7, 23) on the
  alternate frame and showed it at (0, 8) when CMD restored the primary
  buffer. Both controls left the cursor visible on the alternate frame.
- **Viewport and marker.** The fixed runtime matched all 24 viewport and
  fixed-row resize requests at row offset 0. The fixed-row marker stayed
  in its original buffer position before each of the 12 repaints.
- **Live resize and shell return.** The six CMD and PowerShell resize
  workflows matched all 48 live size checks while drawing and processing
  input. Each app was running at the check before the final 100×30 resize
  and had exited at the check afterward. The restored frame matched the
  native snapshot with the primary marker at (2, 1). All 15 shell workflows
  reported exit code 37 and ran the next edited command.
