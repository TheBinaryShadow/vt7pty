## What coordination establishes

All 117 existing prototype baseline cases and nine new expiry controls pass.
The auditor binds each of 126 owned mutation scopes and 99 borrowed focused
scopes to its exact host request and agent lease. Protected scopes exclude
scraping, resizing and lease expiry until keyboard-scope completion. Accepted
final responses retain the nested Ctrl state and restoration checks.

All nine receipt-only controls remain ambiguous at the final protocol boundary.
Their private completion marker permits safe resumption; it does not supply
the deliberately missing acknowledgment or prove event delivery. Further
dispatch stays disabled and no retry is sent.

All nine expiry controls refuse before writing a host cancellation request,
disable dispatch and retries, preserve the pending read and original text,
apply the queued resize, and pass subsequent input. No stale lease is renewed
to turn the refused request into a successful cancellation.

All nine prototype neighbors retain 80,148 host-window events and 122,376 agent
events with zero reported loss. Each exceeds the unchanged 4,096-event storage
capacity over its run. There are 221 to 276 drains per trial; the largest actual
gap is 530 ms and the longest drain is 140 ms. The nominal 250 ms interval is
not a strict scheduling guarantee. No prototype core or extended review reports
a coverage gap or operational/resumption issue.

and 81,420 agent events. Those gaps remain disclosed in the reference audits.

recorded neighbor history is stronger evidence than those behavior checks alone.
