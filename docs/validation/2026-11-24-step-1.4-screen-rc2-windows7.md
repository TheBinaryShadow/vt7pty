## What I verified

- **Cursor and restoration.** The fixed runtime hides the VT cursor at
  (7, 23) on the alternate frame and shows it at (0, 8) when CMD restores
  the primary buffer. I checked the commands in the captured byte streams
  and compared them with the native snapshots. The frame, attributes,
  dimensions and cursor position match at both checkpoints.
- **Resize and shell return.** The six fixed-runtime live resize workflows
  matched all 48 viewport and buffer measurements while drawing and
  processing edited input. Each app exited between the checks around the
  final resize. The shell returned at 100×30 with the primary marker intact.
  All 15 fixed-runtime shell workflows returned to a usable prompt and ran
  the next edited command.
