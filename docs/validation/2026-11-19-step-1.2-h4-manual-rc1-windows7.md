## What lock/unlock establishes

Each caller starts and returns on WinSta0\Default at medium integrity. While
locked, OpenInputDesktop is denied with error 5; new opt-in startup refuses
with the matching input-desktop error. That refusal is the expected guard.
The observed inactive intervals are about 14.3 seconds on NESSY, 7.1 seconds on
TURTLE and 9.8 seconds on LEOPARD. These are observation intervals, not measured
lock/unlock latency or exact screen-lock duration.

The original line remains pending with zero control events after unlock.
Cancellation then clears it, the next line reads correctly, and a freshly
opened session passes cancellation and its next read. The caller thread was
not reassigned by the smoke helper, and the test did not switch the input
desktop itself.

Across the nine workflows, I verified 12 complete keyboard-state operations:
the temporary state contains only the required Ctrl presses, and all 256 bytes
match their originals afterward. All 12 retained session lifetimes match
