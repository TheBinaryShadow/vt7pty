## Modernization implemented

- Replaced inherited formatting and conversion helpers with C++20
  `std::format`, `std::to_chars`, streams, spans, byte views, standard
  algorithms, and a checked integral-narrowing facility.
- Removed the custom string builder and test, formatting shim, exception
  indirection, obsolete architecture/compiler macros, and redundant header
  workarounds. `ModernCppTest` now checks the standard formatting and narrowing
  replacements.
- Strengthened move-only and nonthrowing ownership for Win32 handles and
  modules, pipe collections, pool storage, security objects, and temporary
  allocations. Thread and process handles use the same ownership boundary.
- Added scoped enums, typed constants, explicit null/default initialization,
  safer size handling, and stronger RPC buffer bounds.
- Rehomed unit tests under `tests/unit`, the backend test under
  `tests/integration`, the incompatible-agent program under `tests/fixtures`,
  and the debug server source under `tools/debug` using Git-detected moves.
- Defined the maintained namespace and source-layout policy without applying a
  bulk formatting pass or rewriting the proven input, scraper, resize, or
  lifecycle algorithms.
- Replaced the wrap-prone event-loop tick source with Windows 7-compatible
  `GetTickCount64` while preserving the polling contract.
- Resolved the inherited compiler-warning families, enabled `/W4 /WX`, and
  added `Analyze-VT7Pty.ps1` plus the MSVC native analyzer to Release
  verification. The verifier now recreates its result directories so stale
  evidence cannot survive a run.

No third-party dependency was added.
