## Implemented checks

The maintained command, `Verify-VT7Pty.ps1`, runs unit, component, and
integration executables in Debug and Release. The portable runner uses the
same native cases and adds target inventory and a 120-minute soak.

The new controlled child fixture checks ordered output and exact exit status,
console input, Unicode output, 100 alternating resizes while 200 numbered rows
are written, 500 create/output/close cycles after five warm-up cycles, 20
live-session shutdowns, agent and child exit, failed child creation, four
concurrent sessions, and handle stability. Deliberately broken output, exit
status, ordering, truncation, timeout, and handle state must be detected.
Existing agent absence and incompatible-protocol controls remain in the suite.

The local runner writes `tests.json` and `tests.txt` before artifact inspection;
the target runner writes complete JSON and text records, diagnostics and bundles,
and a crash-artifact inventory. Each target record includes package/toolchain,
OS/update, machine, tier, case status, timing, and captured output.
