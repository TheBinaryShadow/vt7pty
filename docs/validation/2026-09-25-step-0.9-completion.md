## Decision and limits

The manual release process and its `0.5.0-dev` candidate are accepted. The
packaging/review gates and all three Windows 7 tier runs now have exact,
attributable evidence. PowerShell 5.1 and `KB3191566` were not required by
the tested native runtime or the legacy target procedure on `LEOPARD`.

This does not qualify an unbuilt `0.5.0` binary or authorize publication.
Changing the version to `0.5.0` changes package bytes and requires a fresh
clean package set and three acceptance runs before a tag or GitHub Release.
This bounded suite also does not establish VT7 integration, terminal fidelity
for the still-unmeasured SSH/full-screen path, or ConPTY compatibility.
