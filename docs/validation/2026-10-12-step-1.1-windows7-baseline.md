## Observed failures and passing comparisons

All three machines reproduce the same F01 failures against unchanged 0.5.0:

| Case | Fresh prompt after Ctrl+C | Canceled text stayed unexecuted | Next command executed / shell alive |
| --- | --- | --- | --- |
| CMD_EMPTY | No | Yes | Yes / Yes |
| CMD_PARTIAL | No | No | Yes / Yes |
| PS_EMPTY | No | Yes | Yes / Yes |
| PS_PARTIAL | No | No | Yes / Yes |

The partial-line recipes type a controlled command without Enter, send byte
0x03, then send a boundary Enter. Both partial cases create cancelled-command.txt
containing BAD on every machine; continued-command.txt contains CONTINUE.
These file barriers establish execution independently of echoed command text.
Failures are native BehaviorMismatch with exit code 1, not missing prerequisites
or timeouts. They are reproducible baseline limitations; the precise input/
ConsoleHost cause still needs diagnosis before a backend change.

The eight controlled native workflows pass on all three targets: positioned
state/attributes, ordered input records, processed and unprocessed Ctrl+C,
the bounded Unicode sample, explicit alternate-buffer restoration, synchronized
resize and final-output drain. PowerShell 7 empty/partial cancellation passes
on both designated A/B machines.

All fixture runs report actual input/output code page 852 and Lucida Console
at 4 by 6 cells. Unicode normalized text and cursor match the backing console:
expected and decoded cursor are both (14, 9). The six raw UTF-16 cell differences
are diagnostics for representation, not normalized text failures. This does
not establish preservation of text already lost in the backing console or
general Unicode width behavior.

Resize finishes with matching cursor (17, 7), window origin (0, 0), and zero
cell/attribute differences. These bounded Windows 7 comparisons pass even though
the development host reported Unicode cursor and resize mismatches. Retain those
[development observations](2026-10-12-step-1.1-candidate.md); do not promote them
to Windows 7 defects or treat this small corpus as full Unicode/resize coverage.
The reader's declared width rules and lack of reflow remain explicit limits.

## Development disposition

The application-identity and tier-applicability item in Step 1.1 now has linked
evidence. The full step remains open: active native-child interruption and
return to each shell prompt still need recipes, as do the broader input/layout,
encoding, erase/wrap/scroll, automatic buffer restoration, sustained full-screen
resize and performance measurements listed in PendingCoverage.

Next, extend the baseline before closing Step 1.1, starting with active-child
interrupts. Preserve the four F01 failures as focused Step 1.2 reproduction
targets and diagnose the classic ConsoleHost input/control path. A fix must
show cancellation without execution of the typed command and a usable fresh
prompt, while retaining processed/unprocessed control behavior and the passing
PowerShell 7 cases.

No runtime source or VT7 file was changed by this evidence review. The published
0.5.0 acceptance remains valid for its original bounded contract; these new
observations establish additional fidelity work.
