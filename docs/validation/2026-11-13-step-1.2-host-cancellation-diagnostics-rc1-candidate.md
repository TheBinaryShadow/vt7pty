## Integrity and limits

The [integrity control](results/step-1.2/host-cancellation-diagnostics-rc1/audit/integrity-control.json)
changes one byte in a copied original control executable and updates its outer
manifest hash. The runner still rejects it against the pinned original manifest
before creating results or launching native processes. Separate
[reviewer controls](results/step-1.2/host-cancellation-diagnostics-rc1/controls/reviewer/controls.json)
reject a forged nested host PID and a late observation attached to a passing
case while their original native summaries still say Pass.

The [preservation inventory](results/step-1.2/host-cancellation-diagnostics-rc1/preserved-files.json)
covers 2,333 copied files, each checked byte for byte. It includes the exact
package run, both final native trace runs, preliminary trace observations,
verification reports, negative controls and reproduction scripts. Preliminary
records describe instrumentation development and are not candidate acceptance.

The target runner supports installed PowerShell 2.0 through the existing
Windows 7 helpers. This local run uses PowerShell 5.1; execution of the new
runner on LEOPARD remains pending alongside NESSY and TURTLE. Instrumentation
changes timing and shell preparation, so traced passes cannot replace failed
controls. The
[investigation questions](2026-11-13-step-1.2-host-cancellation-rc1-investigation.md)
remain the basis for reviewing those results. H3, H4 and runtime integration
remain open.
