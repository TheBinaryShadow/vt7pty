## What rc3 resolved

- LEOPARD completed the clean and layered Windows PowerShell fixtures in all
  three repetitions and the eight physical checkpoints using its installed
  PowerShell 2.0 and CLR 2.0.50727.8806. It ran the full legacy collection
  without KB3191566.
- The manual startup reached Ready in every shell. The first F8 command, helper
  loading and snapshot publication each had a same-shell acknowledgment.
  TURTLE inherited a 180 by 63 window in both engines. Its display buffer fit
  that window, and both engines passed resize readback.
- Native clean-shell fingerprints matched all 35 controlled and manual
  startups. Windows PowerShell 5.1 on NESSY and TURTLE reported one
  System.IO.FileNotFoundException in both environments. PowerShell 2.0 and
  PowerShell 7.2.24 reported zero. The layered cases verified profile precedence
  and the configured editors. All six layered PSReadLine 2.1.0 runs rejected
  History prediction on the legacy console and restored None. History recall
  and the custom F6 binding passed.

## Physical input

I verified eight checkpoints per shell in Windows PowerShell 5.1 and
PowerShell 7.2.24 on NESSY and TURTLE, and in Windows PowerShell 2.0 on
LEOPARD. Each manual result links to the completed automated collection
from its machine. The checkpoints cover startup, editing, history, completion,
multiline entry, prompt cancellation, a native child, and resize. Each native
child received one Ctrl+C, each shell exited with status 37, and owned
processes cleaned up.

All five shells started with normal profiles enabled and recorded all four
profile scopes as empty. This qualifies ordinary startup and input in those
configurations. The controlled cases exercise the four profile scopes and
their load order through inline fixtures. The manual receipts retain metadata
and command matches with personal output, history and typed text excluded.
