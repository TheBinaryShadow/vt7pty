## CPU, handles and memory

I recorded 7,942 active operations across 24 trials. All 72 idle process
intervals recorded zero CPU time change. Only 11 of 72 active intervals
recorded a change, with zero on TURTLE. The nonzero values were
multiples of about 15.6 ms. I need a more sensitive measurement for
the CPU budget.

The screen rc3 caller held five more handles and used 132 to 152 KiB
more maximum sampled private memory. Each runtime's caller gained one
handle during the active window in every trial. Agent and fixture
counts held at 45 and 8. Both runtimes passed the 500-session
post-warm-up handle check on all three machines.
