## Active-child behavior

Every applicable active-child case passes: nine on NESSY, nine on TURTLE and
six on LEOPARD, for 24 passing observations across the targets.

| Policy | Native observation and completion |
| --- | --- |
| Processed, handled Ctrl+C | Exactly one CTRL_C_EVENT, no key records, final output and deliberate native exit 37 |
| Processed, default handler | Native exit 0xC000013A, reported by the shell as -1073741510; no final packet or output marker required |
| Unprocessed Ctrl+C | Ordered Ctrl+C and z key records, one repeat each, no control event, Ctrl released before z; final output and native exit 37 |

All cases return to a usable parent prompt, execute the next command through
a file barrier, preserve the expected native/shell-reported status and clean
up their owned processes. Actual processed modes are 487 for CMD/installed
PowerShell and 503 for PowerShell 7; unprocessed modes are 416 and 432
respectively. The oracle checks the relevant bits rather than one hardcoded
whole mode value.

These passing workflows are regression guards for future input changes.
Sending an additional control event indiscriminately would risk duplicate
delivery or altered child/parent behavior.

## Six retained cancellation failures

CMD_EMPTY, CMD_PARTIAL, PS_EMPTY and PS_PARTIAL fail on every target. Neither
shell produces the required fresh prompt after Ctrl+C. Both partial cases
leave the typed command intact: boundary Enter creates cancelled-command.txt
containing BAD. The next command creates continued-command.txt containing
CONTINUE, and the shell remains alive. These file markers establish execution
independently of echoed input.

Both cooked-read cases also fail on every target:

| Case | Delivery path | After Ctrl+C | After boundary Enter |
| --- | --- | --- | --- |
| READCONSOLE_TRANSPORT | VT byte 0x03 through unchanged VT7Pty | Handler count 1, CTRL_C_EVENT, ReadConsoleW still pending | Successful read returns PROBE_TYPED plus CRLF |
| READCONSOLE_EVENT | GenerateConsoleCtrlEvent inside owned fixture | Handler count 1, CTRL_C_EVENT, ReadConsoleW still pending | Successful read returns PROBE_TYPED plus CRLF |

The initial mode is 135: processed, line and echo input with extended flags.
The pre-interruption echo barrier establishes that the read consumed typed
input without completing. All six probe observations retain the text, exit
with the fixture's deliberate status 37 after recovery, and clean up normally.
They are BehaviorMismatch failures, not missing prerequisites or harness errors.

The target probes confirm that successful control-handler signal delivery
does not cancel the pending cooked read in this tested configuration. Direct
fixture generation reproduces the same gap independently of the transport's
VT decoder. This matches the retained
[input-path comment](../../src/agent/ConsoleInput.cc) and supports cooked-read
cancellation as the explanation to investigate for the matching real-shell
prompt failures. The shell implementation itself has not been instrumented
to prove every internal cause.

## Other comparisons and development disposition

Bounded state/attributes, ordered input records, root processed/unprocessed
control cases, explicit buffer restoration, Unicode, resize and final drain
pass on all three targets. Unicode normalized text and cursor match at (14, 9);
raw UTF-16 representation differences remain diagnostics. Resize ends at
cursor (17, 7) and window origin (0, 0), with matching cells and attributes.
PowerShell 7 prompt cancellation passes on A/B. These results preserve the
distinction from the development host's Unicode/resize mismatches and do not
qualify general width, reflow or sustained full-screen behavior.

The rc3 target extension is now measured. Step 1.1 still has seven broader
coverage groups: distinct Ctrl+Break representation; full key/mouse/layout
and ordinary profiles; code-page/malformed-input matrix; automatic buffer
restoration; sustained full-screen resize; performance budgets; and live
erase/wrap/scroll transitions.

The next focused input work is designing a user-mode mechanism that cancels
classic cooked input without executing retained text. It must preserve the
now-measured active-child policies, avoid duplicate control delivery and keep
PowerShell 7 working. Broader baseline work remains required before closing
Step 1.1; fixes need focused regressions and their own target evidence before
acceptance.

No runtime source or VT7 file was changed by this review. The original 0.5.0
release acceptance and 120-minute soak remain separate bounded qualification
records; these short fidelity runs neither replace them nor constitute a
new release.
