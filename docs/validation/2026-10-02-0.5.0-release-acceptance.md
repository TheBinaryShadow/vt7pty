## Decision and limits

The exact `0.5.0` release package passes the local packaging gates, all three target acceptance runs, and the independent release review. It is ready for a `v0.5.0` tag at the source commit and a GitHub Release carrying the six unchanged assets. This bounded suite establishes the declared baseline platform and test contract; SSH/full-screen fidelity, VT7 integration, and ConPTY compatibility remain future work.
