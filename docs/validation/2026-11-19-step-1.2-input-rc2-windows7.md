guards preserve 174 canceled-read observations and 237 exact subsequent reads.
I verified ordinary application desktops, private backing hosts, retained

independent reviewers. No collector error or ambiguous delivery remains.

All 24 native Ctrl+Break references pass, including six from the frozen cohort.
The 18 candidate references cover processed and unprocessed modes on all nine
input repetitions. They verify the child's group identity, one Break event,
zero Ctrl+C, no parent notification and natural exit. Public VT7Pty Break
transport remains Unsupported by the approved decision.

I qualify this parser change within the
[input/reply contract](../INPUT_FIDELITY.md#input-and-reply-contract). Standalone
Escape still uses the one-second fallback, and the byte interface retains the
cursor-report/modified-F3 ambiguity while a query is outstanding. Reply bytes
must be serialized as documented. These are explicit API considerations, not
new latency or general ConPTY-compatibility claims.

Ordinary-user-profile coverage remains NotRun. I did not execute personal
profile scripts or repeat the earlier physical keyboard, lock/unlock or full
soak qualification for this narrow parser change. Step 1.2, Milestone 1 and
VT7 integration remain open. The next work is the remaining input coverage;
this matrix does not need to be repeated.
