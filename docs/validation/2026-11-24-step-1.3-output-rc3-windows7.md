## Code pages and replay results

The combining and CJK samples occupy the same cells on all three targets
at the default page 852 and requested pages 437, 852 and 65001. The
snapshots all show Lucida Console at 4 by 6 pixels per cell. The 12
CP936 attempts return error 87, retain page 852 and skip the dependent
write. The six original raw VT cases also report the capability unavailable.

The independent reviewer recomputed all 48 available replays from the
retained snapshots and bytes. All 48 preserve the expected native code
points and final cursor in the original replay. The bar still moves by
one column under the reference reader. Columns below start at zero.

| Sample | Native bar | Original replay | One-cell replay | Replay with cursor move |
| --- | ---: | ---: | --- | --- |
| e plus U+0301 | 4 | 3 | Row, bar and cursor match | Bar at 4. The accent attaches to e and leaves a blank before the bar. |
| U+4E2D | 3 | 4 | Row, bar and cursor match | Bar at 3. The write hits the second cell and erases the ideograph in the test reader. |

The one-cell replay reproduces these Windows 7 samples. WOLF stores
U+4E2D in two cells at page 852 with the same reported face and cell size.
There the one-cell replay shifts a correctly placed bar. A fixed rule
based on the page and reported font can therefore give the wrong result.
