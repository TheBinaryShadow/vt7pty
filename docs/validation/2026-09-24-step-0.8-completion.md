## Decision

Step 0.8 is accepted. Its permanent local and portable test system detects
the specified positive and negative behaviors and produces attributable,
machine-readable evidence. Its source passed local Debug and Release
verification, and the exact package passed all 30 target cases on both accepted
Windows 7 tiers. These bounded runs left no unexplained crash, hang, orphan,
data loss, or material resource regression. Milestone 0 continues with Step
0.9, the manual release process. The SSH/full-screen fidelity baseline remains
the documented
[Milestone 1 dependency](../SSH_BASELINE.md).
