## Diagnostics implemented

- Native records are bounded JSON lines with ISO 8601 UTC timestamps,
  severity, subsystem, exact package/commit/API/protocol identity, process,
  PID, TID, and escaped single-line messages.
- Every record is smaller than 4,096 bytes. Busy-pipe and transaction waits
  are each bounded at 100 milliseconds, and `OutputDebugString` remains an
  independent debugger sink.
- `VT7Pty-DebugServer.exe` now has owner/System/administrators-only pipe
  security, remote-client rejection, bounded complete-record file output,
  an 8 MiB default and 64 MiB maximum file limit, `--version`, and a live
  `--self-test`. The inherited Everyone-write option was removed.
- `New-VT7PtyDiagnosticBundle.ps1` packages the bounded log, parsed counts,
  exact build identities, host servicing inventory, package identity, and
  shipped-binary hashes. It flags known opt-in input-record forms.
- The package includes the collector, diagnostic procedure, and native
  security review. The Windows 7 runner exercises the real diagnostic pipe,
  validates three structured records, enforces a 4 KiB test-file ceiling,
  creates a bundle, and validates its manifest on the target.

Default traces no longer contain agent command lines, application-facing
error messages, control/data pipe names, or raw pipe handles. Keyboard and
mouse content remains behind the explicit `VT7PTY_DEBUG=trace,input` opt-in.

## Security review and hardening

The [native boundary review](../SECURITY_REVIEW.md) records controls and
dispositions for every reviewed boundary. Implemented changes include:

- removal of the broad debug-pipe descriptor;
- exact spawned-agent PID validation on the restricted control pipe;
- explicit dispositions for application-selected data-pipe connectors and
  caller-controlled child executable resolution;
- a 1 MiB client-agent control-packet ceiling on both input and output;
- malformed length, field, Boolean, flag, resize, and message-type rejection
  through controlled pipe closure and agent shutdown;
- a 32,767-character ceiling and terminator check for environment blocks; and
- confirmation that client-to-agent handle inheritance is disabled and that
  CONERR child inheritance is limited to the deliberate console handles.

Executable/DLL lookup, command-line quoting, temporary paths, numeric
conversions, buffer boundaries, overlapped cancellation, and shutdown
ownership have explicit reviewed dispositions. No Step 0.7 blocker remains.
