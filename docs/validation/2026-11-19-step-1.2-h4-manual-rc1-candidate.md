## What I fixed

The raw input reader had no visible echo. Enabling console echo alone would
not fix a bridge using ReadConsoleInputW; Windows documents that echo mode
applies to ReadFile and ReadConsole in
[SetConsoleMode](https://learn.microsoft.com/en-us/windows/console/setconsolemode).
I now render a local preview immediately, including Backspace, and separately
show the application's actual readback. Exact backend checks still decide
whether the step passes.

I show the required and current console layout, wait for Enter confirmation,
and keep waiting if the layout is wrong. Each text-bearing key retains its
actual layout identifier. A layout query that is not yet available cannot
silently confirm a profile. The key files and UI transcript are retained as
the run progresses, including partial evidence after F12 or failure.
