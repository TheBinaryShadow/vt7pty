The integrated suite uses the real DLL, agent, host module and public input pipe.
It covers ordinary application/descendant GUI placement, cooked/raw routing,
repeated cancellation, exact next reads, Enter races with both outcomes,
concurrent RPC/input/close, abrupt agent/caller death, enclosing-job inheritance,
neighbor isolation, recreation, real impersonation denial, missing/wrong helper
modules, shell prompts and active children.

I added a dedicated close thread after reviewing the initial thread-pool monitor.
I also moved desktop creation off the consumer's API thread, retained monitor
resources until host exit, and restored keyboard state after any attempted
temporary update. These details still need target qualification.
