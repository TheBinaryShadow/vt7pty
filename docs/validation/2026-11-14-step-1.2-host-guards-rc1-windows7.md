## What the guards establish

All 126 baseline and expiry cases pass. The additional guards qualify these
controlled behaviors:

| Guard group | Passing cases | Evidence |
| --- | ---: | --- |
| Completion races and cohort coverage | 36/36 | 27 concurrent Enter/cancel trials; both outcomes occur in every cohort |
| Concurrent research-channel close | 27/27 | Close requested during an active request; resources retained through completion |
| Actual access denial | 9/9 | Restricted-token OpenThread fails with error 5; credentials and input recover |
| Active native children | 60/60 | Single event, expected route contract, exit 37, parent reports 37 and continues |
| PowerShell 7 prompts | 24/24 | Native editing and bundled PSReadLine pass their distinct input routes |

The [comparison](results/step-1.2/host-guards-rc1/windows7/comparison.json)
and [aggregate metrics](results/step-1.2/host-guards-rc1/windows7/audit/metrics.json)
retain the per-trial records.

The 27 completion contenders produce 15 completed reads and 12 canceled reads.
Completed reads retain exactly racekeep followed by CRLF. Canceled reads discard
the old text, report ERROR_OPERATION_ABORTED and deliver one event. Every recorded
input fence and subsequent NEXT_PROBE read passes. These are concurrent
controller requests; I make no claim of simultaneous kernel execution.

The 27 close guards cover publication before notification, keyboard completion
before response consumption, and missing final acknowledgment. Each closes the
research channel while retaining the active request's resources. Subsequent
dispatch is refused. These checks do not exercise concurrent production
vt7pty_free or qualify the production API lifetime contract.

The auditor binds 222 owned coordination scopes, with no borrowed scopes,
nine expiry refusals and eighteen receipt-only scopes. A keyboard completion
marker never replaces a missing final acknowledgment. Unknown outcomes disable
dispatch and retries; no fallback control event is sent.

All nine real denial controls preserve the pending line and subsequent input
without installing a new hook or writing a cancellation request. They restore
the original credentials and ordinary thread access. This covers an actual
same-user restricted-token denial; cross-integrity and elevated-host policy
remain H4 requirements.

The active-child matrix covers CMD and installed Windows PowerShell on all
three machines, plus PowerShell 7 native editing and PSReadLine on NESSY/TURTLE.
The public ETX route retains the established event/normal-exit contract. The host
route additionally requires an aborted cooked read and an intact second child
read. Public ETX cancellation of a pending cooked read remains a recorded
limitation. PSReadLine prompt cancellation stays on ordinary public input and
requires no host mutation.
