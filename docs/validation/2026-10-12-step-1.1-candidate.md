## Implemented scope

- An independent bounded VT state reader with strict UTF-8, cursor, cells,
  attributes, erase, scroll, wrap, fragmentation, title/mouse metadata and DSR
  handling. Its corpus width rules and lack of reflow are explicit.
- A controlled native fixture with a bounded private test pipe, current-user/
  SYSTEM ACL, local-client restriction, peer PID validation and snapshots of
  cells, modes, geometry, cursor, code pages and font.
- Native comparisons for positioned state, input records, processed and
  unprocessed Ctrl+C, a Unicode sample, explicit alternate-buffer restoration,
  synchronized resize and final-output drain.
- Empty/partial prompt cancellation through clean Command Prompt, Windows
  PowerShell and exact PowerShell 7.2.24. PowerShell 7 uses bundled PSReadLine,
  Windows editing, prediction disabled and session-local SaveNothing history.
- Case-level machine-readable results, raw controlled streams and snapshots,
  application/module hashes before/after the run, and eight fault controls.
- PowerShell 2.0-compatible target orchestration and separate non-ESU, ESU and
  legacy launchers. Legacy uses installed PowerShell 2.0 and excludes KB3191566;
  PowerShell 7 is outside its required initial corpus.

The [runner instructions](../FIDELITY_BASELINE.md) and
[fidelity plan](../FIDELITY.md) define exact applicability. The initial suite
has 23 entries: one oracle unit suite, 14 workflow observations and eight fault
controls. Broader recipes remain explicitly NotRun in cases.json and the report.
There is no full-coverage or milestone-completion claim.

## Local verification

Debug and Release build under /W4 /WX with MSVC v143 14.44.35207 and Windows
SDK 10.0.26100.0. Both final clean-source local regression/inspection runs
pass their existing 29 entries; the 120-minute soak is not part of these
local runs. It remains a separate existing Windows 7 milestone/release gate.

The Release static-analysis rebuild passed after moving large snapshot objects
to owned heap storage; warnings were corrected rather than disabled. Independent
VT reader tests pass in Debug and Release, including malformed/truncated input,
cell/attribute/cursor mutations, wide-cell overwrite/erase, geometry bounds,
argument quoting and UTF-8 JSON metadata.

The maintained verifier also inspects the new binaries' imports, manifests,
resources and Windows 7 subsystem floor. Observed direct dependencies:

| Binary | Imports |
| --- | --- |
| VtStateTest.exe | KERNEL32.dll |
| FidelityFixture.exe | KERNEL32.dll |
| FidelityTest.exe | ADVAPI32.dll, KERNEL32.dll, VT7Pty.dll |

Static inspection is not physical Windows 7 execution. Fixture-channel
cancellation waits for I/O completion before releasing OVERLAPPED storage,
following [Microsoft's cancellation guidance](https://learn.microsoft.com/en-us/windows/win32/fileio/canceling-pending-i-o-operations).
Peer validation uses the documented
[client PID API](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getnamedpipeclientprocessid).

The package integrity control rejected an altered/incomplete bundle before
case execution. The checksum path guard was also checked independently.

## Unchanged-runtime development comparison

The extracted final archive ran on WOLF, Windows 10 IoT Enterprise LTSC
10.0.19044, X870 Pro RS, Windows PowerShell 5.1.19041.7725 and CLR
4.0.30319.42000. Results are preserved in
[the initial evidence directory](results/step-1.1/README.md).

Exact portable PowerShell 7.2.24 was used from ignored development artifacts;
its [official release](https://github.com/PowerShell/PowerShell/releases/tag/v7.2.24)
ZIP SHA-256 matched A1CCB6D8AD52F917470A136C3752AF4465F261BCBE570CF44F52AA69AE6E867E.
The PowerShell 7 sessions loaded PSReadLine 2.1.0; installed Windows PowerShell
on WOLF auto-loaded PSReadLine 2.0.0, unlike the native ConsoleHost target sessions.
This test copy is not shipped in
the baseline bundle and does not change global installation or profile settings.

All 23 entries executed: 19 Pass and four Fail, zero NotRun. The independent
oracle and all eight negative controls passed; owned-process cleanup passed
for every native observation. Application/module hashes stayed stable.
HarnessHealthy and CharacterizationComplete are true for the implemented
initial corpus; MilestoneAccepted is false.

| Workflow | Observation |
| --- | --- |
| Command Prompt, empty line | Ctrl+C did not produce the required fresh prompt; the next command still executed |
| Command Prompt, partial line | Typed command remained and executed after boundary Enter; next command and shell lifetime remained usable |
| Unicode sample | Normalized text matched the backing console, but cursor column was 13 versus expected 15 |
| Resize | A one-row state/cursor offset remained; the console window origin changed during resize |
| Other initial workflows | State/attributes, input records, both controlled Ctrl+C modes, explicit buffer restore, drain and both PowerShell cancellation variants passed |

These are preserved development-host mismatches, not newly introduced
regressions or accepted Windows 7 defects. The Unicode width and resize results
need target evidence and independent consumer-policy review. The reader does
not model general Unicode width or terminal reflow. Raw UTF-16 cell difference
counts are diagnostics, separate from normalized text equality.

The earlier dirty-source development smoke was used only to debug the harness.
It is not the delivered candidate's qualification record.
